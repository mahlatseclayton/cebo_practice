BEFORE YOU START

Program structure

Every Java program lives inside a class, and runs from the main method. The file name must match the class name, so this goes in Main.java.

import java.util.Scanner;        // imports go at the very top

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
  • Every statement ends with a semicolon ;
  • Blocks are wrapped in braces { }
  • Java is case sensitive: String is correct, string is an error.
  • Comments: // one line and /* many lines */

LU 6

Objects, random numbers and method overloading

Classes and instantiating an object

A class is a blueprint. An object is one instance built from it with the keyword new. Fields store what the object knows; methods are what it can do.

public class Learner {
    // Fields (attributes)
    private String name;
    private int grade;
    private double mark;

    // Constructor: same name as the class, no return type
    public Learner(String name, int grade, double mark) {
        this.name = name;
        this.grade = grade;
        this.mark = mark;
    }

    // Getters (accessors) and a setter (mutator)
    public String getName()  { return name; }
    public double getMark()  { return mark; }
    public void setMark(double mark) { this.mark = mark; }

    public boolean hasPassed() { return mark >= 50; }

    public String toString() {
        return name + " (Gr " + grade + "): " + mark + "%";
    }
}
public class Main {
    public static void main(String[] args) {
        Learner l1 = new Learner("Naledi", 11, 72.5);   // instantiate
        Learner l2 = new Learner("Kabelo", 11, 44.0);

        System.out.println(l1);                  // calls toString()
        System.out.println(l2.getName() + " passed: " + l2.hasPassed());
        l2.setMark(55);
        System.out.println(l2);
    }
}
Naledi (Gr 11): 72.5%
Kabelo passed: false
Kabelo (Gr 11): 55.0%
  • private fields can only be used inside the class. Outside code uses the getters and setters.
  • this.name means the object's field; name alone means the parameter.
  • Scanner, Random and DecimalFormat are also objects you instantiate with new.

Range formulaA random whole number from low to high inclusive: rand.nextInt(high - low + 1) + low, or (int)(Math.random() * (high - low + 1)) + low.

Method overloading

Two or more methods with the same name but different parameter lists (different number, types or order). Java picks the one that matches the arguments. Return type alone does not count.

public class Calculator {
    public static int add(int a, int b)             { return a + b; }
    public static int add(int a, int b, int c)      { return a + b + c; }
    public static double add(double a, double b)    { return a + b; }

    public static void main(String[] args) {
        System.out.println(add(2, 3));        // 5
        System.out.println(add(2, 3, 4));     // 9
        System.out.println(add(2.5, 1.5));    // 4.0
    }
}

Constructors can be overloaded too:

public Learner(String name) {              // only a name supplied
    this(name, 10, 0);                     // calls the 3-parameter constructor
}

LU 8

Switch statements and comparing strings

Comparing strings

String a = "Yes";
a.equals("Yes");               // true   content is the same
a.equals("yes");               // false  case matters
a.equalsIgnoreCase("YES");     // true
a.compareTo("No");             // positive: "Yes" comes after "No" alphabetically
"Apple".compareTo("Banana");   // negative: Apple comes first
"cat".compareTo("cat");        // 0: equal
a.compareToIgnoreCase("yes");  // 0
Why not ==For Strings, == checks whether two variables point to the same object in memory, not whether the text matches. It can give the wrong answer with input from Scanner. Always use .equals().

Switch statement

Compares one variable against fixed values. Works with int, char and String (not double or boolean).

int day = sc.nextInt();
switch (day) {
    case 1:
        System.out.println("Monday");
        break;
    case 2:
        System.out.println("Tuesday");
        break;
    case 6:
    case 7:                                  // two cases share one block
        System.out.println("Weekend");
        break;
    default:                                // no case matched
        System.out.println("Invalid day");
}
  • break exits the switch. Without it, execution falls through into the next case.
  • default runs when nothing matches. It is optional but expected in exams.
  • Case values must be constants, not ranges. For mark >= 50 use an if.

Switch on a String or char

System.out.print("Enter a province code: ");
String code = sc.nextLine().toUpperCase();     // make input case-insensitive
switch (code) {
    case "GP": System.out.println("Gauteng"); break;
    case "WC": System.out.println("Western Cape"); break;
    case "KZN": System.out.println("KwaZulu-Natal"); break;
    default: System.out.println("Unknown");
}

char op = sc.next().charAt(0);
switch (op) {
    case '+': System.out.println(a + b); break;
    case '-': System.out.println(a - b); break;
    case '*': System.out.println(a * b); break;
    case '/': System.out.println((double) a / b); break;
    default: System.out.println("Invalid operator");
}

Arrow form (Java 14+)

String type = switch (day) {
    case 6, 7 -> "Weekend";
    default -> "Weekday";
};   // no break needed

While loops

Use while when you do not know in advance how many times to repeat. The condition is checked before each pass.

while (condition) {
    // body: must eventually make the condition false
}

int count = 1;
while (count <= 5) {
    System.out.print(count + " ");

A loop inside another loop. For every single pass of the outer loop, the inner loop runs completely. Use them for anything with rows and columns: patterns, tables, grids, or comparing every item with every other item.

    for (int col = 1; col <= 4; col++) {      // inner: columns

LU 11

Methods: separating main from the rest of the code

Instead of writing everything inside main, break the program into small methods that each do one job. main then reads like a list of steps. This is easier to read, test and reuse, and it earns marks for structure.

Method structure

// access  static  returnType  name(parameters)
public static double calcAverage(int total, int count) {
    return (double) total / count;
}
KindReturn typeCalled as
void method (procedure)void, returns nothingshowMenu(); on its own line
Return method (function)int, double, String, boolean...double avg = calcAverage(t, n);
  • Parameters are the variables in the method heading. Arguments are the values you pass in when calling it.
  • Arguments must match the parameters in number, type and order.
  • Variables declared inside a method are local: other methods cannot see them.
  • A return method must return a value of its type on every path.
  • Methods called from static main must also be static (or be called on an object).

Before: everything in main

public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    System.out.print("Enter mark: ");
    int m = sc.nextInt();
    while (m < 0 || m > 100) { System.out.print("Invalid: "); m = sc.nextInt(); }
    String sym;
    if (m >= 80) sym = "A"; else if (m >= 70) sym = "B";
    else if (m >= 60) sym = "C"; else if (m >= 50) sym = "D"; else sym = "F";
    System.out.println("Symbol: " + sym);
}

After: separated into methods

import java.util.Scanner;

public class Results {
    static Scanner sc = new Scanner(System.in);   // shared by all methods

    public static void main(String[] args) {
        int mark = getValidMark();
        String symbol = getSymbol(mark);
        displayResult(mark, symbol);
    }

    // Return method: reads and validates input
    public static int getValidMark() {
        System.out.print("Enter mark (0-100): ");
        int m = sc.nextInt();
        while (m < 0 || m > 100) {
            System.out.print("Invalid. Try again: ");
            m = sc.nextInt();
        }
        return m;
    }

    // Return method: processing only, no input or output
    public static String getSymbol(int mark) {
        if (mark >= 80) return "A";
        if (mark >= 70) return "B";
        if (mark >= 60) return "C";
        if (mark >= 50) return "D";
        return "F";
    }

    // Void method: output only
    public static void displayResult(int mark, String symbol) {
        System.out.println("Mark: " + mark + "%  Symbol: " + symbol);
    }
}

Methods in a separate class

Often the exam gives you an object class (LU 6) and a driver class that holds main. The driver creates objects and calls their methods.

// File: Rectangle.java
public class Rectangle {
    private double length, width;
    public Rectangle(double l, double w) { length = l; width = w; }
    public double area()      { return length * width; }
    public double perimeter() { return 2 * (length + width); }
}

// File: RectangleDriver.java
public class RectangleDriver {
    public static void main(String[] args) {
        Rectangle r = new Rectangle(5, 3);
        System.out.println("Area: " + r.area());            // 15.0
        System.out.println("Perimeter: " + r.perimeter());  // 16.0
    }
}
LU 12

SQL 25% of marks

SQL (Structured Query Language) is used to ask a database questions and change its data. Your queries are marked on whether they return exactly the right rows and columns, so read every question carefully.

Structure of the data

  • A database holds one or more tables.
  • A table is made of fields (columns) and records (rows).
  • The primary key uniquely identifies each record, for example LearnerID. It may not repeat or be empty.
  • A foreign key is a field in one table that refers to the primary key in another table, linking them.
  • Each field has a data type: text, number (integer or real), date/time, boolean (yes/no), currency.

Query structure

The clauses must appear in this order. Only SELECT and FROM are required.

SELECT   fields                -- which columns
FROM     table                 -- which table
WHERE    condition             -- which rows (before grouping)
GROUP BY field                 -- combine rows into groups
HAVING   condition             -- which groups (after grouping)
ORDER BY field ASC | DESC    -- sort the result

SELECT and FROM

SELECT * FROM tblLearners;                         -- all fields, all records
SELECT FirstName, Surname, Mark FROM tblLearners;   -- chosen fields only
SELECT DISTINCT Grade FROM tblLearners;             -- no duplicates: 11, 10

WHERE: filtering records

SELECT * FROM tblLearners WHERE Grade = 11;
SELECT * FROM tblLearners WHERE Gender = 'F';                  -- text in quotes
SELECT * FROM tblLearners WHERE Mark >= 50 AND Grade = 10;
SELECT * FROM tblLearners WHERE Mark < 50 OR Mark > 90;
SELECT * FROM tblLearners WHERE NOT Gender = 'M';
SELECT * FROM tblLearners WHERE Mark BETWEEN 60 AND 80;        -- inclusive
SELECT * FROM tblLearners WHERE ClassID IN ('C1', 'C3');
SELECT * FROM tblLearners WHERE ClassID IS NULL;               -- empty field

= <> < > <= >=Comparisons. <> means not equal
AND OR NOTCombine conditions
BETWEEN x AND yIn a range, both ends included
IN (a, b, c)Matches any value in the list
LIKEPattern match on text

LIKE and wildcards

SELECT * FROM tblLearners WHERE Surname LIKE 'M%';     -- starts with M
SELECT * FROM tblLearners WHERE Surname LIKE '%i';     -- ends with i
SELECT * FROM tblLearners WHERE FirstName LIKE '%h%'; -- contains h
SELECT * FROM tblLearners WHERE FirstName LIKE '_a%'; -- second letter is a
Wildcards differ by programStandard SQL and Java database connections use % (any number of characters) and _ (exactly one). MS Access uses * and ?, and puts dates between hashes: #2010/01/23#. Use whichever your exam software expects.

ORDER BY: sorting

SELECT FirstName, Mark FROM tblLearners ORDER BY Mark DESC;         -- highest first
SELECT * FROM tblLearners ORDER BY Grade ASC, Surname ASC;          -- by grade, then surname

ASC (A to Z, smallest first) is the default.

Calculated fields and aliases (AS)

SELECT FirstName, Mark, Mark * 1.1 AS AdjustedMark FROM tblLearners;
SELECT FirstName & ' ' & Surname AS FullName FROM tblLearners;   -- Access joins text with &
SELECT CONCAT(FirstName, ' ', Surname) AS FullName FROM tblLearners; -- MySQL style
SELECT FirstName, ROUND(Mark / 100 * 150, 1) AS OutOf150 FROM tblLearners;

Aggregate functions

SELECT COUNT(*) AS NumLearners FROM tblLearners;          -- 5
SELECT AVG(Mark) AS AverageMark FROM tblLearners;         -- 66.6
SELECT SUM(Mark) AS Total FROM tblLearners;               -- 333
SELECT MAX(Mark) AS Highest, MIN(Mark) AS Lowest FROM tblLearners;  -- 91, 45
SELECT COUNT(*) FROM tblLearners WHERE Mark < 50;          -- 1

GROUP BY and HAVING

GROUP BY makes one result row per group. Every field in SELECT that is not inside an aggregate must appear in GROUP BY.

SELECT Grade, COUNT(*) AS Learners, AVG(Mark) AS Average
FROM tblLearners
GROUP BY Grade;
Grade | Learners | Average
10    | 2        | 56.0
11    | 3        | 73.67
-- Only groups with an average above 60
SELECT Grade, AVG(Mark) AS Average
FROM tblLearners
GROUP BY Grade
HAVING AVG(Mark) > 60;

-- Count of boys and girls in Grade 11
SELECT Gender, COUNT(*) AS Total
FROM tblLearners
WHERE Grade = 11
GROUP BY Gender;
WHERE vs HAVINGWHERE filters individual records before grouping and cannot use aggregates. HAVING filters groups after grouping and is where conditions like COUNT(*) > 2 or AVG(Mark) > 60 go.

Date and text functions

SELECT FirstName, YEAR(DOB) AS BirthYear FROM tblLearners;
SELECT * FROM tblLearners WHERE MONTH(DOB) = 12;           -- born in December
SELECT * FROM tblLearners WHERE DOB < '2010-01-01';
SELECT FirstName, 2026 - YEAR(DOB) AS Age FROM tblLearners;
SELECT UCASE(Surname), LEN(FirstName) FROM tblLearners;     -- Access: UCASE, LEN
SELECT LEFT(FirstName, 1) & '. ' & Surname AS Initials FROM tblLearners;  -- T. Mokoena

Joining two tables

Link tables where the foreign key equals the primary key, so you can show fields from both.

-- Using WHERE
SELECT tblLearners.FirstName, tblClasses.Teacher, tblClasses.Room
FROM tblLearners, tblClasses
WHERE tblLearners.ClassID = tblClasses.ClassID;

-- Using INNER JOIN (same result)
SELECT L.FirstName, C.Teacher
FROM tblLearners L INNER JOIN tblClasses C ON L.ClassID = C.ClassID
WHERE C.Teacher = 'Mr Khumalo';
FirstName | Teacher
Pieter    | Mr Khumalo
Naledi    | Mr Khumalo

Manipulating data

-- INSERT: add a new record
INSERT INTO tblLearners (LearnerID, FirstName, Surname, Gender, Grade, DOB, Mark, ClassID)
VALUES (6, 'Zanele', 'Mthembu', 'F', 10, '2010-05-18', 83, 'C2');

-- UPDATE: change existing records
UPDATE tblLearners
SET Mark = 55
WHERE LearnerID = 3;

UPDATE tblLearners
SET Mark = Mark + 5               -- add 5 to every Grade 10 mark
WHERE Grade = 10;

-- DELETE: remove records
DELETE FROM tblLearners
WHERE Mark < 30;
Always use WHERE with UPDATE and DELETEWithout a WHERE clause, UPDATE changes every record and DELETE FROM tblLearners; empties the whole table.

Subquery

-- Learners who scored above the average
SELECT FirstName, Mark
FROM tblLearners
WHERE Mark > (SELECT AVG(Mark) FROM tblLearners);
